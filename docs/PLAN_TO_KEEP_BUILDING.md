### 1. "How to Add the Next Case" Protocol

Future portfolio case studies will follow a standardized **3-Beat Structure**:

* **Beat 1 — The Problem:** State what was broken, manual, or unverified (e.g., data drift, manual SQL checks).
* **Beat 2 — What I Did:** Detail the concrete engineering action taken with proof (e.g., DuckDB MCP query execution, AST query parsing).
* **Beat 3 — What Came of It:** State the quantitative outcome or published artifact (e.g., 0 grain duplicates across 100,000 rows, automated data contract published).

**Publishing Process:**
1. Open workspace in Google Antigravity IDE (`Search-Intel-Portfolio-Builder`).
2. Input terminal logs into the agent to convert them into a 3-beat HTML card using established Identity Kit design tokens.
3. Paste the returned HTML snippet into `docs/index.html`.
4. Run `git add docs/index.html && git commit -m "feat: publish new case study" && git push origin main`.
