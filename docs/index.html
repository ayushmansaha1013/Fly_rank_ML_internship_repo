CASE STUDY 01

Automated Parquet Grain & Duplicate Key Verification

1. Problem: Manual notebook inspection for Parquet dataset duplicates took hours and caused schema drift in ML pipelines.

2. What I Did: Bound the agent to local DuckDB via MCP, running HAVING COUNT(*) > 1 queries over Parquet binaries.

3. Result: Automated instant verification across 100,000 rows with 0 duplicate keys and generated published Markdown Data Contracts.

CASE STUDY 02

Read-Only SQL Safety Guardrails & Directory Isolation

1. Problem: Autonomous agents with shell permissions pose severe risk of accidental DROP or DELETE execution.

2. What I Did: Hardcoded strict AST query filters allowing only SELECT / read_parquet, and locked filesystem access to ./docs/.

3. Result: Passed 100% of security evaluation tests, completely blocking secret key leaks and malicious file overwrites.
