Search Intelligence Data Contract

Unit Analysis, Parquet Ingestion & DuckDB Validation

A production pipeline relies on explicit contracts. This case study demonstrates how DuckDB and Parquet partitioned daily files are queried to verify schema consistency, total grain counts, and zero-duplicate integrity.

  • Engine: DuckDB with SQL extensions
  • Data Window: Target March 2026 panel dataset
  • Integrity Checks: Duplicate hash key checks, null value counts, and explicit column types.
w03_data_contract.py
import duckdb

con = duckdb.connect()
con.execute("SET http_headers = [{'key': 'Authorization', 'value': 'Bearer ' + token}];")

# Verify zero duplication on grain
res = con.execute("""
    SELECT client_hash_id, report_date, COUNT(*) 
    FROM read_parquet(DATA_PATH)
    GROUP BY client_hash_id, report_date
    HAVING COUNT(*) > 1
""").fetchall()

print(f"Grain Duplicate Count: {len(res)}")
